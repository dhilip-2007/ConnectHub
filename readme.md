## 📌 About the Project

**ConnectHub** is a social networking web application designed to provide a simple and interactive environment for connecting with friends, sharing updates, and discovering content.

The application demonstrates common social media features through a responsive frontend interface. It is developed using standard web technologies and is suitable for beginners learning frontend development.

## ✨ Features

### 📝 Posts
- Create text posts.
- Optionally add an image using an image URL.
- View posts in a feed.
- Delete posts created by the current demo profile.
- Display post information and engagement counts.

### ❤️ Social Interactions
- Like and unlike posts.
- Add comments to posts.
- Share post text using supported browser features.
- Bookmark posts for later.
- Filter liked and bookmarked posts.

### 📸 Stories
- View demo stories.
- Add a text-based story.
- Navigate between available stories.

### 🔍 Search and Discovery
- Search posts by text, author, or username.
- Filter content using available feed options.
- Navigate through application sections.

### 👥 Friends
- View demo friend profiles.
- Display online and offline indicators.
- Explore the sample friends list.

### 🎨 User Interface
- Responsive layout for desktop and mobile screens.
- Light and dark themes.
- Interactive buttons and menus.
- Toast notifications.
- Profile editing in the demo interface.
- Keyboard shortcuts for selected actions.

### 💾 Browser Storage
- Save demo posts and interactions in browser local storage.
- Preserve the selected theme.
- Retain demo data after refreshing the page in the same browser.

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/dhilip-2007/ConnectHub.git
```

### 2. Open the project folder

```bash
cd ConnectHub
```

### 3. Open in Visual Studio Code

```bash
code .
```

### 4. Run the application

Open `index.html` using the **Live Server** extension in Visual Studio Code.

Alternatively, open `index.html` directly in a modern web browser.

## 🌍 Deploy on GitHub Pages

Follow these steps to publish ConnectHub online.

1. Open the [ConnectHub GitHub repository](https://github.com/dhilip-2007/ConnectHub).
2. Navigate to **Settings**.
3. Select **Pages** from the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch.
6. Select the `/ (root)` folder.
7. Click **Save**.
8. Wait for GitHub Pages to complete the deployment.

Your expected live website address is:

**https://dhilip-2007.github.io/ConnectHub/**

Make sure the main HTML file is named `index.html` and is located in the repository root.

## 🔄 Update Your GitHub Repository

After editing your files, open the VS Code terminal in the ConnectHub project folder and run:

```bash
git add .
git commit -m "Update ConnectHub project"
git push origin main
```

If Git reports that the remote repository is not configured, add it once:

```bash
git remote add origin https://github.com/dhilip-2007/ConnectHub.git
git branch -M main
git push -u origin main
```

If `origin` already exists, do not add it again. Check the configured remote using:

```bash
git remote -v
```

## ⚠️ Current Limitations

ConnectHub is currently a **frontend demonstration**, not a complete production social network.

- Demo data is stored locally in the browser.
- Other users cannot see your locally created posts.
- There is no real account authentication.
- Messaging and online status are demonstrations only.
- Stories are not shared with other users.
- Some features depend on browser support and valid image URLs.

A backend and database would be required to support shared accounts, real messaging, and synchronized content.
